# Flint Hall RA Team: Weekly Update

Static site for the weekly RA update. Each week is one file in `content/weeks/`.

To add a week: copy the latest file in `content/weeks/`, rename it to the meeting date (YYYY-MM-DD.json), edit it, then run `python3 build.py`. Commit and push.

Public site: keep resident and RA personal information off it.
